# Archive

Everything in this folder is dated history: finished plans, hand-offs, studies and old notes. They are kept so the reasons behind past work are not lost, but none of them is a current instruction, and many describe code, settings or decisions that have since changed.

Each document sits in a folder named for the month it was written (for example `2025-04/`), with its original file name. To learn how something works today, read the code. To learn why something was decided, read the decisions log in the main repository (`docs/decisions.md`), which wins over anything here.
